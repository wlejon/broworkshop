Exploring Modern DOM Range & Selection APIs

The DOM Range interface represents a fragment of a document that can contain nodes and parts of text nodes. In combination with the Selection object, web applications can accurately manipulate text spans, track caret positions, and apply rich typography.

Select any segment of this text to observe the live telemetry in the right-hand inspection panel. You can test boundary-crossing operations like surroundContents, extract fragments into memory, or insert dynamic stamp nodes.

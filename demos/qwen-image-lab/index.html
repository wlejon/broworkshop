The text backbone is idle from prime() onwards. Releasing it buys 8.5 GiB — a rendered prompt stays available through the 8-entry prompt memo, an unseen one throws until it is reloaded.

axis bank 88 minted axes

These carry the authority: 8–25σ of readout travel against 4.4σ for the best in-network dial. Applied to every token row of the conditioning at prime() time — the model sees the sum, which is what the budget holds.

stack budget 0 = uncapped

Over budget every active axis is scaled by one common factor, so the mix you dialled in survives and only the overdrive is shed.

mint an axis diff of means · the v2 recipe

A pole difference is pooled per encode, the attention-sink dimensions are zeroed, the mean is unit-normalised and the bank scale is 0.15 × this run's own mean token norm.

the desk controller.json

global

Each fader moves one perceptual axis and leaves the others alone. 1.0 ≈ tau sigmas of its own readout; the safe range is ±2, and past it pushing harder swaps the picture rather than moving the axis.

travel & retention vs the untouched render

render with the desk at zero to set a baseline

Retention is a structural-similarity proxy against the baseline (no CLIP in the app). Round 3's bar was 0.71 similarity — below it the fader is replacing the picture, not moving an axis.

schedule one curve per armed control

Edit the curves on the Schedule tab. A lane at 1.0 means the control is at its full setting on that step; at 0 it is off. An axis lane is armed with qwenImage21AddControlSchedule and is taken out of the prime-time stack, because a schedule composes with setControl.

cost what a curve pays for

Rebuilding the conditioning rows drops the prefix K/V cache, so a step whose alpha MOVED pays one extra prefill and a step whose alpha sat still pays nothing. A flat schedule costs one re-extract for the whole run; a window costs two, entering and leaving.

gate multipliers 1.00 = neutral

img rows are the image being generated and are free to move mid-denoise; txt rows are the cached prefix and re-extract when touched.

block band half-open [lo, hi)

32 blocks. One modulation vector drives all of them, so a band is realised as a second copy of that vector for the blocks inside it.

gate delta post-tanh · reaches past ±1

A mod delta lands before the tanh, where 74% of the gate2 channels have tanh′ < 0.05. This one has unit authority on every channel — and a gate above 1 is not otherwise reachable.

mask brush paint it on the render →

Paint a region in the Gate Paint tab. A mask over a centre disc puts 95% of its pixel change inside a region covering 28% of the frame, and localisation improves the later it is armed.

regions none

Paint them on the Spatial tab. Each region carries a gate multiplier — the model's only per-token hook, armed at the region's own step — and, optionally, axes of its own. Axes are global by construction, so that half is composited: a second state from the same seed, stepped in lockstep and blended back under the region every step, so the join happens inside the denoiser.

selected —

modulation delta fraction of the model's own vector

The delta is a fraction of that chunk's own value at the current step — chunk norms run 21 to 189, so an absolute add would mean four different things in four places.

norm_out scale one knob on output magnitude

prefix K/V free, mid-denoise, survives a re-extract

Attenuating V fades the prompt's contribution while leaving the attention pattern it induces intact; K alone flattens that pattern instead.

prefix slots —

The extracted prefix is the conditioning as far as every step after the first is concerned. Saving one and blending towards it is a prompt crossfade below the text encoder entirely: no re-encoding, no vision tower, no txt_in — a lerp over cached K/V that lands on the very next step.

blend A → B, no re-encode

The live prefix is set to A, then blended towards B: (1−t)·A + t·B. Both slots must describe the same layout — same prefix length, same target grid — which in practice means two prompts that tokenize to the same length. A mismatch throws rather than mis-aligning.

walk N frames from A to B

The frames render at the size the slots were saved at, not the scene's — a cache carries its target grid, so there is no cheap small preview of one. A slot card turns amber when this scene is rendering at another size.

What re-extracts, and what is free: the TEXT half of the prefix is rebuilt whenever the conditioning rows change — a txt gate multiplier, a gate mask, an edited row, a control-schedule alpha that moved — and costs one prefill (+13% on that step). The IMAGE half of a mask, the prefix-K/V dial and a slot blend are all read where the cache is used, so they are free mid-denoise and survive every re-extract.

Each image enters twice: through the Qwen3-VL vision tower (so the prompt is about the picture) and through the 16× autoencoder (so the pixels are in the joint sequence). The prompt says what to change.

The text backbone is idle from prime() onwards. Releasing it buys 8.5 GiB — a rendered prompt stays available through the 8-entry prompt memo, an unseen one throws until it is reloaded.

axis bank 88 minted axes

These carry the authority: 8–25σ of readout travel against 4.4σ for the best in-network dial. Applied to every token row of the conditioning at prime() time — the model sees the sum, which is what the budget holds.

stack budget 0 = uncapped

Over budget every active axis is scaled by one common factor, so the mix you dialled in survives and only the overdrive is shed.

the desk controller.json

Each fader moves one perceptual axis and leaves the others alone. 1.0 ≈ tau sigmas of its own readout; the safe range is ±2, and past it pushing harder swaps the picture rather than moving the axis.

travel & retention vs the untouched render

render with the desk at zero to set a baseline

Retention is a structural-similarity proxy against the baseline (no CLIP in the app). Round 3's bar was 0.71 similarity — below it the fader is replacing the picture, not moving an axis.

gate multipliers 1.00 = neutral

img rows are the image being generated and are free to move mid-denoise; txt rows are the cached prefix and re-extract when touched.

block band half-open [lo, hi)

32 blocks. One modulation vector drives all of them, so a band is realised as a second copy of that vector for the blocks inside it.

gate delta post-tanh · reaches past ±1

A mod delta lands before the tanh, where 74% of the gate2 channels have tanh′ < 0.05. This one has unit authority on every channel — and a gate above 1 is not otherwise reachable.

mask brush paint it on the render →

Paint a region in the Gate Paint tab. A mask over a centre disc puts 95% of its pixel change inside a region covering 28% of the frame, and localisation improves the later it is armed.

modulation delta fraction of the model's own vector

The delta is a fraction of that chunk's own value at the current step — chunk norms run 21 to 189, so an absolute add would mean four different things in four places.

norm_out scale one knob on output magnitude

prefix K/V free, mid-denoise, survives a re-extract

Attenuating V fades the prompt's contribution while leaving the attention pattern it induces intact; K alone flattens that pattern instead.

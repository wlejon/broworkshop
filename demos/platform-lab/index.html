Web Animations element.animate() — same interpolator as CSS transitions, same bro.time clock

The two columns below are the point — the stated time on the left comes from the Animation object, the measured style on the right comes from getComputedStyle(). CSS border-image Backgrounds-3 §6 nine-slice


        

            Nine-slice borders have no JS API, so “it looks right” is the only thing a
            screenshot can tell you. Two seams make it actually verifiable. First, every
            sample below is declared with the shorthand —
            source || slice [/ width]? [/ outset]? || repeat, a grammar
            where token class rather than position decides meaning — and the five
            expanded longhands are read straight back out of

            (assets/nine.png, generated by tools/make_frames.js)

            the corner of the window can be sampled with getPixel() to

Compression Streams brokit, miniz-backed — ?


        

            CompressionStream and DecompressionStream are
            transform streams, not functions, and demonstrating them as one-shot calls
            would hide everything that makes them streams. So the bench pipes data
            through with pipeThrough, counts chunks in both
            directions, and includes a 256 KB incompressible payload written in 4 KB
            pieces — a codec that buffered everything would emit one chunk and still
            pass a naive round-trip test.

Container bytes the only thing distinguishing the three formats on the wire

        

            All three formats round-trip against themselves even if they were secretly
            the same codec — so the bench also checks the wire format:
            gzip must start 1f 8b 08 and carry a little-endian
            uncompressed size in its final four bytes; deflate must open with
            a zlib CMF/FLG pair whose big-endian value is a multiple of 31; and
            deflate-raw must be neither.
        


        
Error surface

        

            Failure modes are part of the API and the easiest part to get quietly wrong —
            a decoder that “recovers” from truncated input is worse than one that throws.
            Unknown formats reject at construction; corrupt, truncated, cross-format and
            trailing-garbage input errors the stream.
        

        


        
Practical: compressed localStorage

        

            Storage is a string store, so persisting compressed bytes needs a base64 hop —
            which is exactly the shape every real “compress before you persist” path has,
            and worth showing to scale (base64 gives back a third of what gzip saved).

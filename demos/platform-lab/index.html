Web Animations element.animate(): same interpolator as CSS transitions, same bro.time clock

A script animation in bro is not a separate clock: it rides the engine's scaled bro.time clock, composites like a CSS animation, and is driven deterministically by advanceTime(ms) in headless. The two columns below are the point: the stated time comes from the Animation object, the measured style from getComputedStyle(). The app computes neither.

Compression Streams brokit, miniz-backed: ?

      

        CompressionStream and DecompressionStream are transform
        streams, not functions. The bench pipes data through with pipeThrough,
        counts chunks in both directions, and includes a 256 KB incompressible payload
        written in 4 KB pieces; a codec that buffered everything would emit one chunk and
        still pass a naive round-trip.

Container bytes what distinguishes the three formats on the wire

      

        All three formats round-trip against themselves even if they were secretly one codec,
        so the bench checks the wire format too: gzip starts
        1f 8b 08 and ends with a little-endian uncompressed size;
        deflate opens with a zlib CMF/FLG pair divisible by 31;
        deflate-raw is neither.
      


      
Error surface

      

        A decoder that "recovers" from truncated input is worse than one that throws. Unknown
        formats reject at construction; corrupt, truncated, cross-format and trailing-garbage
        input errors the stream.
      

      


      
Practical: compressed localStorage

      

        Storage holds strings, so persisting compressed bytes needs a base64 hop, the shape
        of every real "compress before you persist" path (base64 gives back a third of what
        gzip saved).

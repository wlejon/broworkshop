bro.time one engine clock, globally scaled

Every arcade game in this tree hand-rolls its own pause flag. bro.time.paused already freezes timers, rAF, CSS transitions, physics and audio, across every window and iframe at once, and bro.time.scale gives slow motion for free.

Lunar lander a real game with no pause flag in it

There is no pause flag in this game. Its flight integrator, fuel burn, respawn setTimeout and pad-beacon setInterval all read the engine's scaled clock, so bro.time.paused = true (one assignment, nowhere near the game's code) freezes all of them together, and bro.time.scale = 0.3 gives bullet-time landings for free.

statusflying ←→ tilt · ↑ thrust · R reset · Q slow-mo · Space pause · hold the mouse to thrust

The powerup eases bro.time.scale down to 0.30×, holds, then eases it back: the timescale is a continuous dial, not a toggle. The ramp is clocked off the frame count rather than the scaled clock on purpose: a ramp timed in scaled time slows its own recovery down as it works.

bro.json startup keys launch-only, made explorable

borderless, alwaysOnTop, min/maxWidth/Height, windowX/windowY and display are read once at engine construction. Declared (this app's bro.json) beside what bro.window reports now: change anything in the host panel and a row drifts. These keys are defaults, not bindings.

Zero-copy transfer and the exit door

        
postMessage(msg, transfer) hands an ArrayBuffer's memory to the
          child instead of copying it. The proof is the detachment: our buffer comes back
          byteLength 0, which a copy could never do, while the child's checksum of the arrived bytes
          matches the one taken before sending. Send it as a plain clone to see our buffer survive.

        

          
        

        

          
          
          
        

        

        

        
window.open(url) hands off to the OS

        
A URL with its own scheme goes to the default browser or mail client via
          SDL_OpenURL and the call returns null: there is no popup window object.
          This leaves the app. Arm the checkbox first; headless never shells out.

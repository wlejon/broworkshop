bro.time one engine clock, globally scaled

scale 1.00×

Every arcade game in this tree hand-rolls its own pause flag. bro.time.paused already freezes timers, rAF, CSS transitions, physics and audio — across every window and iframe at once — and bro.time.scale gives slow-motion for free.

Lunar lander a real game with no pause flag in it

There is no pause flag in this game. Its flight integrator, its fuel burn, its respawn setTimeout and its pad-beacon setInterval all read the engine's scaled clock, so bro.time.paused = true — one assignment, nowhere near this game's code — freezes every one of them together, and bro.time.scale = 0.3 gives bullet-time landings for free. All 32 games in ../../games gate their loops on hand-rolled run-state flags instead, and none of them touches bro.time at all.

status flying ←→ tilt · ↑ thrust · R reset · Q slow-mo · Space pause

The powerup ramps bro.time.scale down to 0.30×, holds, then eases it back — timescale is a continuously drivable dial, not a toggle. The ramp is clocked off the frame count rather than the scaled clock on purpose: a ramp timed in scaled time slows its own recovery down as it works.

Zero-copy transfer and the exit door

        

            postMessage(msg, transfer) hands an
            ArrayBuffer's memory to the child instead of copying
            it. The proof is the detachment: our buffer
            comes back byteLength 0 and every view onto it goes to
            length 0, which a copy could never do — while the child's checksum
            of the arrived bytes matches the one we took before sending. Send
            the same payload as a plain clone to see our buffer survive instead.

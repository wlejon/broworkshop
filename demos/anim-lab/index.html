Clips

Library

Each button is play(name) with the current loop flag and speed — a hard cut, no fade. Every clip is generated keyframe data compiled to a bromesh Animation; the engine evaluates it in C++.

Transport

stop fades the player out to bind pose and deactivates it — that is the T-pose you see, not a bug. Speed goes negative: the gait runs backward. Scrubbing writes animationTime, which re-poses immediately even while paused.
Crossfade

Blend into a clip

The outgoing clip keeps advancing while it fades, so walk → run stays foot-aligned instead of snapping. Set fade to 0 and hit the button to feel the difference a crossfade makes.
Blending

Base mix

Blend space on the base track

A blend space is a base-track citizen: these are play(spaceName), the same call the clip grid makes. Clip buttons above take the base back.

1D — speed axis

One scalar picks the mix of idle@0 → walk@1.6 → run@5.0. The two neighbouring clips blend by position, and all members share one normalized phase, so the feet stay aligned at any mix rather than sliding.

2D — direction

Drag the pad — or hit a preset. X is strafe, Y is forward/back, with idle at the centre. The three nearest sample points blend by inverse-squared distance, so a corner is a genuine three-way mix, not a lerp along an edge.
Layers

Masked layers 0/3

Walk and wave at once. Put the 2D or 1D space on the base, push the speed up, then switch on slot 1 — the legs keep coming from the blend space while the arms come from the layer. The three rows default to disjoint masks (right arm / left arm / head), so all three can run over the gait simultaneously. Change a mask to full body and the layer swallows the walk entirely: that is the mask doing its job, in reverse.
Rig

Skeleton

The overlay reads getBoneWorldMatrix() per bone per frame and parks a marker there — the same seam a prop socket or a ragdoll would attach through. Turn the mesh off to watch the rig alone.

Animation Lab

bro's skeletal animation tower on one character: clips, crossfades, blend spaces, masked layers, a state machine, root motion and camera nodes — keyframe data evaluated in C++, nothing posed from JavaScript

Graph

The lit node is node.state. Click a state to travel() to it — the same authored transition the parameters fire automatically.

Each transition carries its own fade; sync is syncPhase (a crouch mid-stride keeps its feet), auto is autoAdvance (the engine leaves a one-shot by itself).

Parameters

These name no state: they move a number and a boolean. Push speed past 0.05 and idle → move fires; tick crouch and move → moveCrouch does. The engine owns the graph, the app owns the decision.

Transitions

onStateChanged(from, to) on the virtual clock. A jump logs two lines — the wildcard in, the auto-advance out.

Root motion

travelled 0.00 m passed 0/7 markers node z 0.00

Switch this on with the machine's speed up. Off, the character treadmills: the gait's displacement stays in the pose. On, setRootMotion pulls it out and consumeRootMotion() hands it to the app, which walks the node down the 1.5 m marker run. The animation is the source of truth for distance, so the feet never slide.

Camera nodes

position

scene.createCamera() makes the camera a NODE; its world transform is the view. follow is parented to the character and rides root motion with zero per-frame JS. Cinematic flies the wide camera from a createAnimationPlayer clip.

Library

Each button is play(name): a hard cut that suspends the state machine (node.state goes null); travel to any state to re-enter.

Transport

stop fades to bind pose — the T-pose is intended. Negative speed runs the gait backward. Scrubbing writes animationTime and re-poses even while paused.

Crossfade

The outgoing clip keeps advancing while it fades, so walk → run stays foot-aligned. Set fade to 0 to feel the difference.

Base mix

Blend space on the base track

A blend space is play(spaceName) — the same call a clip button makes.

1D — speed axis

idle@0 → walk@1.6 → run@5.0. Neighbours blend by position on one shared phase, so the feet stay aligned at any mix.

2D — direction

Drag the pad or hit a preset. X is strafe, Y is forward/back. The three nearest samples blend by inverse-squared distance, so a corner is a genuine three-way mix.

Masked layers 0/3

Walk and wave at once. Put a blend space on the base, push the speed up, then switch on slot 1: legs from the space, arm from the layer. The default masks are disjoint, so all three run together. Set a mask to full body and the layer swallows the walk.

Skeleton

The overlay reads getBoneWorldMatrix() per bone per frame. Those are MODEL-space matrices, so the markers are parented to the character node and stay glued to the rig under root motion.

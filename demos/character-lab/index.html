innerBody tag—
in overlapShape—
ball verdict—
ball past you—
closest approach—
On: an overlapShape standing exactly where you stand returns you. Off: the same query finds nothing, and every ray in the Sensing section stops hitting SELF. The controller still walks the course either way — the world just cannot see it.
The ball is a separate lesson, and a correction to the docs. It is not affected by this checkbox: measured both ways, the trajectory is identical, because CharacterVirtual resolves its own contacts with dynamic bodies whether or not the broadphase can see it. What DOES change the ball is Push strength in the Controller section — drop it to 0 N and the same throw sails clean through you.

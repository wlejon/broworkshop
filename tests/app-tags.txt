# Tags for scripts/validate.sh.
#
#   <glob> <tag> [tag ...]
#
# <glob> matches an app directory (demos/kws-lab) or a test script path
# (tools/node-forge/tests/test_kokoro_node.js); a script inherits its app's
# tags and adds its own. Later lines win for timeout=.
#
# Tags:
#   ml         needs model weights and a GPU, and is slow. Skipped unless
#              validate.sh is given --ml (or --only-ml).
#   net        needs the network or an API key. Skipped unless --net.
#   skip       never run (interactive, destructive, or not a test at all).
#   timeout=N  per-run timeout in seconds (default 60 smoke / 300 test; ml 900).

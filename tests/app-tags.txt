# Tags for scripts/validate.sh.
#
#   <glob> <tag> [tag ...]
#
# <glob> matches an app directory (demos/kws-lab) or a test script path
# (tools/node-forge/tests/test_kokoro_node.js); a script inherits its app's
# tags and adds its own. Later lines win for timeout=.
#
# Tags:
#   ml         needs model weights and a GPU, and is slow. Skipped unless
#              validate.sh is given --ml (or --only-ml).
#   net        needs the network or an API key. Skipped unless --net.
#   skip       never run (interactive, destructive, or not a test at all).
#   timeout=N  per-run timeout in seconds (default 60 smoke / 300 test; ml 900).
#   needs=NS   needs the engine namespace NS (bro.tensor, bro.ai.game.nn, ...).
#              Skipped when the engine reports it { available: false }, i.e.
#              compiled out of this build profile (the app profile has no
#              AI tower). Prefer an in-test check when only part of a script
#              needs the feature, so the rest still runs.
#   grant=CAPS capabilities (comma-separated) granted to the run beyond what
#              the app's bro.json declares (every run gets --grant declared):
#              for a test that itself reaches outside the app, e.g. writes
#              tests/out under the repo root. Not a stand-in for declaring
#              what the app needs at run time.

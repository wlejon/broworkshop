Worker Sim

copy this folder to run a simulation on a worker thread: the page only draws the frames it is handed

Threads

Mouse

Drag on the canvas. Left attracts, right repels, middle or Shift+drag spins a vortex.

How it works

sim/worker.js steps sim/physics.js on its own timer and transfers each frame as a Float32Array. The page draws it and transfers it back, so no frame is ever copied between threads. Commands go through lib/kit/worker-rpc.js.
